# Crazy Cars

3D mobile arcade kart racing game built with Unity.

## Current milestone
- Android-first mobile prototype
- Arcade kart physics
- 3-lap races
- AI bots
- Item pickups: Turbo, Freeze, Bomb, Shield
- Mobile touch controls
- GitHub Actions APK build pipeline

## Unity
Use Unity 6.3 LTS with Android Build Support, Android SDK/NDK Tools, and OpenJDK.
